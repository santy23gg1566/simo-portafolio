¿Cómo se publica un cambio?

1
Elige qué vas a modificar

Selecciona una sección desde este panel y abre el editor.

2
Inicia sesión con GitHub

La cuenta debe tener permiso de escritura sobre el repositorio. Si sale incorrect_client_credentials, corrige primero el Client ID y Client Secret en Netlify.

3
Pulsa Publicar

Decap guarda el archivo en GitHub. Netlify publicará la nueva versión después del despliegue.

Acceso privado: cualquiera puede conocer la URL /admin/, pero solamente alguien autorizado a escribir en GitHub puede modificar tu sitio. El panel no lleva contraseñas incrustadas.
