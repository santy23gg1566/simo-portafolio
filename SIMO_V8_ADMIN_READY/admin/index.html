Conexión GitHub + Netlify

El panel guarda archivos JSON en el repositorio y Netlify publica automáticamente cada commit.

1
Conecta GitHub

Usa el botón de la barra superior para autorizar tu cuenta mediante Netlify OAuth.

2
Edita cualquier sección

Los textos, opciones y proyectos se modifican dentro de este panel.

3
Guarda los cambios

Se crea un commit en santy23gg1566/simo-portafolio, rama main.

4
Comprueba Netlify

Cuando el despliegue esté Published, la web mostrará lo que guardaste.

Ver GitHub ↗
Si aparece «incorrect_client_credentials», debes corregir Client ID y Client Secret en Netlify → Security → OAuth. Ningún archivo HTML puede solucionar credenciales incorrectas.

Herramientas y respaldo

El contenido actual puede exportarse como copia JSON de seguridad.

No se almacenan contraseñas ni tokens en el código del sitio. El token de GitHub vive temporalmente en memoria, solo mientras la pestaña está abierta.
